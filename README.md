# CreditIQ

CreditIQ is a web-based financial technology prototype designed to evaluate loan applicants using financial and behavioral indicators. The system calculates a credit score and determines loan eligibility using predefined scoring algorithms and risk assessment techniques.

The platform aims to provide a simplified, intelligent, and accessible credit evaluation process for individuals and small businesses that may lack traditional banking records.

## Project Structure

- `auth/` - PHP login and registration pages.
- `financial-info/` - Financial information form and related assets.
- `assessment/` - Python credit assessment script.

## Run Locally

- Open `financial-info/index.html` in a browser to view the financial form.
- Serve `auth/` through a PHP-capable local server to test login and registration.
- Run `python assessment/credit_assessment.py` to use the command-line assessment script.
